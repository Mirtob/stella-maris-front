## 📝 Glosario de Términos

**Cantoral:** Colección de cantos organizados para una Misa específica

**Ordinario de la Misa:** Partes fijas de la Misa (Kyrie, Gloria, Santo, Cordero de Dios)

**RLS:** Row Level Security - Seguridad a nivel de fila en PostgreSQL

**JWT:** JSON Web Token - Token de autenticación

**BaaS:** Backend as a Service - Supabase

**PostgREST:** API REST auto-generada desde PostgreSQL

**PWA:** Progressive Web App

**Tiempo Litúrgico:** Período del calendario litúrgico (Adviento, Navidad, Cuaresma, Pascua, Tiempo Ordinario)
