# Manuales de usuario — Stella Maris

Guías según el rol de cada persona en la app.

| Manual | Para quién | Contenido |
|---|---|---|
| [Pueblo fiel](MANUAL-PUEBLO-FIEL.md) 🙏 | Fieles que siguen la Misa | Instalar la app, elegir parroquia/capilla, ver y **escuchar los cantos** (modo radio), notificaciones, QR. |
| [Coro](MANUAL-CORO.md) 🎵 | Miembros del coro | **Armar y publicar cantorales**, calendario litúrgico, color y revisión litúrgica, QR + folleto PDF, publicados/historial, cursos. |
| [Canal y Contenido](MANUAL-CANAL-Y-CONTENIDO.md) 🎬 | Encargado del canal / Administrador | Subir videos con metadatos `STELLA_MARIS_META`, partituras en Drive, **sincronizar YouTube → app**, herramientas de administración, seguridad del canal. |

> App: **https://stella-maris-front.vercel.app/**
>
> **Importante:** para que los usuarios puedan reproducir cantos y los coros armar cantorales, el
> catálogo debe estar poblado. Eso lo hace el encargado del canal etiquetando los videos y
> sincronizando (ver el *Manual del Canal*).
